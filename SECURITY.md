# Security

## Reporting a problem

Report a security problem privately, through GitHub's private vulnerability
reporting: the repository's **Security** tab, then **Report a
vulnerability** (https://github.com/ryanmitts/deptheos/security/advisories/new).
Please don't open a public issue or discussion for it. If you can't use
GitHub, email support@deptheos.com with "Security" in the subject.

Say what is affected (the app and its version, as About Deptheos shows it),
how to reproduce it, and what it lets someone do. A file that triggers it
is welcome as an attachment to the private report.

You'll get an answer within a week. Once a fix is released, the advisory is
published with credit to you, unless you'd rather not be named.

## What is in scope

The latest release of the desktop app (macOS, Windows, Linux), the command
line tool and the iPhone and iPad app: for example, a frame, RAW, DNG or
Library file that makes an app run code, write outside the folders it
should, or crash in a way that could be exploited; and the update check.
A problem in a third-party library the apps include is welcome too, and is
reported upstream as well. The website (deptheos.com) is static pages;
report a problem with it the same way.

## Supported versions

Only the latest release gets fixes. Deptheos is at 0.x: update to the newest
version before reporting.
